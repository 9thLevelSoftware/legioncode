DESCRIPTION
  Investigate a LegionCode problem on this machine with Claude Code, Codex, or Antigravity, and help file a good issue.

USAGE
  legioncode triage [flags]

FLAGS
  --base-dir string    Explicit LegionCode data directory; runtime state is stored under userdata (equivalent to LEGIONCODE_HOME).
  --agent choice       Agent CLI to use. Default: ask when multiple are installed. (choices: claude, codex, antigravity)
  --model string       Model passed through to the agent CLI. Default: the agent's default.

GLOBAL FLAGS
  --help, -h                                                          Show help information
  --version, -v                                                       Show version information
  --wizard                                                            Start wizard mode for a command
  --completions <bash|zsh|fish|powershell|sh|pwsh>                    Print shell completion script (choices: bash, zsh, fish, powershell, sh, pwsh)
  --log-level <all|trace|debug|info|warn|warning|error|fatal|none>    Sets the minimum log level (choices: all, trace, debug, info, warn, warning, error, fatal, none)
