DESCRIPTION
  Run LegionCode in this terminal and open it in your browser. To use it from your other devices, run `legioncode up`.

USAGE
  legioncode <subcommand> [flags] [<cwd>]

ARGUMENTS
  cwd string    Working directory for provider sessions (defaults to the current directory). (optional)

FLAGS
  --mode choice                              Runtime mode. `desktop` keeps loopback defaults unless overridden. (choices: web, desktop)
  --port integer                             Port for the HTTP/WebSocket server.
  --host string                              Host/interface to bind (for example 127.0.0.1, 0.0.0.0, or a Tailnet IP).
  --base-dir string                          Explicit LegionCode data directory; runtime state is stored under userdata (equivalent to LEGIONCODE_HOME).
  --dev-url string                           Dev web URL to proxy/redirect to (equivalent to VITE_DEV_SERVER_URL).
  --no-browser                               Disable automatic browser opening.
  --bootstrap-fd integer                     Read one-time bootstrap secrets from the given file descriptor.
  --auto-bootstrap-project-from-cwd          Create a project for the current working directory on startup when missing.
  --log-websocket-events, --log-ws-events    Emit server-side logs for outbound WebSocket push traffic (equivalent to LEGIONCODE_LOG_WS_EVENTS).
  --tailscale-serve                          Configure Tailscale Serve to expose this backend over HTTPS on the Tailnet.
  --tailscale-serve-port integer             HTTPS port for Tailscale Serve when --tailscale-serve is enabled.
  --lan                                      Accept connections from your local network and tailnet, not only this machine (equivalent to LEGIONCODE_LAN).

GLOBAL FLAGS
  --help, -h                                                          Show help information
  --version, -v                                                       Show version information
  --wizard                                                            Start wizard mode for a command
  --completions <bash|zsh|fish|powershell|sh|pwsh>                    Print shell completion script (choices: bash, zsh, fish, powershell, sh, pwsh)
  --log-level <all|trace|debug|info|warn|warning|error|fatal|none>    Sets the minimum log level (choices: all, trace, debug, info, warn, warning, error, fatal, none)

SUBCOMMANDS
  help           Show command help.
  serve          Run LegionCode in this terminal, with no browser.
  app            Open a project in the running LegionCode desktop app.
  pair           Mint a pairing token for a running LegionCode server and print it as a QR code.
  auth           Manage the local auth control plane for headless deployments.
  environment    Link other LegionCode environments, so agents here can work there.
  browser        Manage LegionCode's headless browser on this host.
  project        Manage projects.
  thread         Start, message, and read threads on the running server.
  up             Set up remote access and the LegionCode background service.
  status         Show service setup and remote access settings.
  service        Manage the LegionCode background service.
  update         Download a newer legioncode and switch this machine to it, including the background service when one is installed.
  install        Install this version as the `legioncode` command.
  uninstall      Remove legioncode from this machine: the background service, the launcher, and every downloaded version. Your projects and threads are kept.
  theme          Inspect and set environment-wide theme defaults.
  trace          Inspect the local server trace file.
  doctor         Inspect this LegionCode data directory and repair it. Pauses and restarts the background service as needed.
  policy         Inspect the administrator's managed policy.
  triage         Investigate a LegionCode problem on this machine with Claude Code, Codex, or Antigravity, and help file a good issue.
  workflow       Start, inspect and steer durable workflow runs on the running server.
  feedback       Record and inspect local agent feedback reports.
  connect        Set up Legion Connect for this machine. Same as `legioncode up --connect`.
